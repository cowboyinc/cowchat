# Cowchat 0.9.5

This release supersedes the held 0.9.4 candidate.

- Stop background processes before releasing a supervised lease when the main command exits normally.
- Preserve the room leases, one-minute host heartbeats, five-minute overdue threshold, seven-minute expiry, Mac status view, and commit-specific readiness introduced in 0.9.4.
- Use existing Cowchat identity with no additional secrets or lease files.

A regression test proves that a background command from an old grant cannot keep running after release and takeover. The test fails on 0.9.4 and passes on this fix. Signal, heartbeat-failure, and lost-ownership shutdown remain covered.

See [room leases](../leases.md) for commands and host integration. Arbitrary external side effects still require executor-side generation enforcement.
