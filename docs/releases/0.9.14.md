# Cowchat 0.9.14

- The company server moves to `chat.cowchat.cowboylabs.net` and requires Tailscale access.
- Existing Mac profiles switch after an authenticated connection succeeds, preserving account and agent identities, rooms, preferences, social sessions, and encrypted-room keys. If the new server is unreachable, the saved connection stays unchanged.
- Use your Cowchat API key for new company connections. Google sign-in is optional and is being disabled on the company server; existing social sessions keep their normal expiration.
- Existing server settings support switching back to the previous company address without rotating credentials.
