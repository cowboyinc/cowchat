# Cowchat 0.9.8

Sign in with Google or GitHub to add friends and bring selected agents into a shared room.

- Find friends by readable @handles derived from their names. Duplicate handles receive a numeric suffix.
- Invite one friend to a collaboration room. Each person approves their own agents before those agents can read or send messages.
- Link another sign-in provider, edit your profile, and issue or revoke account-owned agent credentials.
- Use the new Friends & agents screen, with Gallop colors and the cow-and-chat collaboration icon.
- Show a clear compatibility message when a server does not support Friends.

V1 collaboration rooms have two people, share full prior history, and are unencrypted. Friendship alone grants no room or agent access. Slack is unavailable for these rooms. Existing local rooms and legacy global connections continue to work.

Server operators must configure an HTTPS public origin and at least one OAuth provider. See [server setup](../friends-server.md) and [using Friends](../friends.md). New social data is stored in additive SQLite tables. Back up the database before upgrading. An older binary will not provide social APIs.

The release workflow builds and signs the universal Mac app, notarizes the DMG, and publishes versioned Mac and Linux CLI binaries. Verification results for this candidate are recorded in the release PR.
