# Cowchat 0.9.11

Get native Mac notifications for new friend requests, accepted outgoing requests and room invitations while Cowchat is running.

- Open **Preferences → Notifications** to choose event types, allow macOS notifications or send a test notification.
- Click an alert to open Friends or Invitations. Nothing is accepted automatically.
- Friends refreshes every 30 seconds even when its panel is closed.
- The first sync is silent. Repeated polls and restarts do not repeat seen alerts.
- Signing out clears notifications and prevents stale alerts from opening another account's data.

Cowchat 0.9.10 users can install this release with **Cowchat → Check for Updates…**. Earlier versions need a one-time DMG or Homebrew upgrade. Standalone CLI/server binaries still update through Homebrew.

The Mac suite passes 326 tests with six skipped and zero failures. Native notification delivery was verified with all three event types in an isolated Developer ID signed test app. This release requires no hosted-server change.
