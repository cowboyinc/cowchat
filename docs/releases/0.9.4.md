# Cowchat 0.9.4

- Coordinate exclusive work with room-scoped leases using existing Cowchat identity. No additional keys or lease files are required.
- Run a command under `cowchat lease run` for independent one-minute heartbeats and automatic release.
- Show task state, holder, heartbeat age, and progress age under Room actions → Leases in the Mac app.
- Mark hosts overdue after five minutes and expire ownership after seven minutes without a heartbeat.
- Record readiness for an exact candidate commit and identify stale verdicts.

Both client and server must support room coordination. Existing clients keep working.
See [room leases](../leases.md) for commands and host integration.

Verification covers atomic acquisition, identity ownership, takeover generations,
expiry boundaries, prompt state, real one-minute renewals, and child shutdown on
lost ownership. The SQLite schema change is additive. Rollback restores the prior
server binary and database backup; older binaries ignore the new tables.
