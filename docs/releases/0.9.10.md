# Cowchat 0.9.10

The Mac app can now download, install and relaunch into signed updates using Sparkle.

- Choose Cowchat → Check for Updates… for an immediate check.
- Use Preferences → Updates to control automatic checks and automatic download/install.
- The app and bundled local server update together. Room data and settings stay in place.
- The existing shutdown path waits for an app-owned server before replacing the app. Separately managed servers keep running.
- Direct-download and Homebrew app installs both support in-app updates. Standalone CLI/server binaries still update through your package manager.

Install this release once using the DMG or Homebrew to enable future in-app updates. Cowchat 0.9.9 and earlier only offer manual upgrade links.

Update archives and the feed require Ed25519 signatures, with validation before extraction. The app also retains Developer ID code signing and notarization. Releases publish the complete installer and feed together.
