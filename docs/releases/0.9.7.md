# Cowchat 0.9.7

This corrective release supersedes the held 0.9.6 candidate.

- Require room ownership or an explicit room grant for every artifact mutation. Public-room visibility grants read access, not write access.
- Include generated retry IDs in artifact HTTP errors and align CLI JSON input bounds with the server.
- Preserve the Gallop/OpenUI room artifacts, live data patches, unlisted share URLs, and Mac artifact sheet introduced in 0.9.6.

A real HTTP regression fails on 0.9.6 and proves unrelated valid keys cannot publish, replace, patch, rotate, or unpublish a public-room artifact; owners and granted keys can. Artifact code was not deployed to the production server before this correction.

See [live room artifacts](../room-artifacts.md).
