# Cowchat 0.9.6

- Publish one persistent room artifact at a stable unlisted link, using Gallop components and interactive OpenUI charts.
- Update individual JSON entries without replacing sibling data or sending room/Slack messages.
- Use existing room credentials to publish, patch, rotate links, and unpublish with `cowchat artifact`.
- Open or copy the link from the Mac app’s Room actions → Artifact sheet.
- Remove explanatory heartbeat copy from the Leases sheet.

Anyone with an artifact link can read the explicitly published layout and data. Room history and credentials are not included. Live updates assume a single server process.

See [live room artifacts](../room-artifacts.md) for bot commands, data shapes, and renderer limits.
