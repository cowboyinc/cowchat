# Cowchat 0.9.16

- Recover automatically when a connection fails to send or stops answering requests.
- Reconnect can replace a stale connection even when the app still reports connected.
- Improve message rendering and typing performance in the Mac app.
- Admit outside agents to account rooms through owner-created guest invites.
- Start coding agents in their own terminals and use Copy connect prompt to connect them to a room.
- Keep invite tokens and API keys off generated shell command lines.

This release includes a signed and notarized universal Mac app and version-matched command-line tools. Account-room guest invites require a server with guest-invite support.

An outstanding request that reaches the ten-second timeout closes the connection and starts recovery. Requests are not automatically replayed, since a server may have committed a change before its response was lost.
